# Ines Portfolio

A modern dark portfolio for Ines Lima, SAP Consultant.

## Files

- `index.html` — site structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation, reveal animations and project modals
- `assets/` — place your photo, CV and future project images here

## Publish on GitHub Pages

1. Open your `ines-portfolio` repository.
2. Click **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
4. Commit the files.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/ (root)**, then save.
8. Your site will be published at:
   `https://YOUR-USERNAME.github.io/ines-portfolio/`
